# Professional portfolio direction

The portfolio presents Richmond Owusu Duah as an early-career transportation engineer at Stantec, with prior civil engineering experience in Ghana, a completed USF master's degree, and an interest in applied research.

## Presentation

- Navy, blue, white, and cool gray, with a readable sans-serif type system.
- Full name, role, professional headshot, and technical focus lead the opening view.
- A persistent desktop sidebar and accessible mobile navigation open focused sections instead of requiring a single long scroll.
- Subtle traffic animation supports the engineering identity. It must pause offscreen, in background tabs, and when reduced motion or a manual pause is selected.
- Real, freely licensed photographs give the project portfolio context. They are credited and never represented as original photographs or proof of work at the photographed sites.

## Content

- Separate entry-level responsibility from team ownership and project outcomes.
- Preserve substantive experience, projects, education, training, leadership, memberships, conferences, volunteering, and relevant interests.
- Project descriptions explain scope, contribution, methods, and deliverables. Avoid promotional slogans, invented performance improvements, and unsupported experience claims.
- Research status is explicit; preprints are identified as preprints.
- No private contact details, client models, source résumés, private repository links, or original photo metadata.

## Validation

Check every view at desktop and mobile widths, browser navigation/deep links, project filtering and disclosures, keyboard behavior, theme and motion controls, image credits, asset loading, privacy boundaries, and a print-ready résumé.

## September 2026 review implementation

The main body type is 16px (1rem), metadata is 12–15px, and headings use moderate letter spacing. Manrope remains self-hosted. Avoid shrinking text to make more content fit; use the focused views, search, and native disclosures instead.

Project search and category filters cover all 22 assignments, including the additional-project register. Matching additional assignments open automatically. Featured project URLs use stable `#project-*` anchors and open their contribution details. Browser Back/Forward restores the reading position within the current visit.

The mobile header uses 44px controls and collapses the résumé label on small screens. Each active view has a primary heading; navigation moves keyboard focus to that heading. The original no-JavaScript content fallback, reduced-motion handling, and manual animation controls remain.

The separate résumé and credits pages use external local stylesheets. Resume screen styles use the same font family and readable text scale; print-specific rules remain unchanged. Do not add external script, font, tracking, or form dependencies.
